# **App Name**: StudyBoost

## Core Features:

- Content Import: Allow users to paste lecture text or upload notes for processing.
- AI Summarization: Utilize the OpenAI API as a tool to automatically summarize the content into concise study notes.
- Flashcard Generation: Leverage the OpenAI API as a tool to generate flashcards (Q&A style) from the summarized content for effective revision.
- Quiz Mode: Enable users to test their knowledge through an interactive quiz mode using the generated flashcards.
- Local Storage: Save flashcards and notes to local storage for offline access and use.
- Export Functionality: Provide options to export flashcards and notes as PDF or CSV files for external use.
- Dark Mode: Implement a dark mode option for comfortable studying in low-light conditions.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) to create a calm and focused environment, reminiscent of traditional study environments without being somber.
- Background color: Very light blue (#F0F8FF) to provide a clean and unobtrusive backdrop that enhances readability and reduces eye strain.
- Accent color: Light purple (#B993D6) to highlight interactive elements and key information, adding a touch of sophistication without distracting from the core content.
- Body and headline font: 'PT Sans', a humanist sans-serif with a balance of modernity and approachability suitable for both headlines and body text, ensuring a readable and engaging user experience.
- Use clear, minimalist icons to represent different functionalities, ensuring intuitive navigation and quick access to essential features.
- Maintain a clean, uncluttered layout with ample white space to avoid overwhelming users and promote focused studying.
- Incorporate subtle animations to provide feedback and guide users through the app, enhancing usability without being distracting.
